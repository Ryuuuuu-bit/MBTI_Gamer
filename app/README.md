# 16 Gamer Heroes: web app (v3, MMO RPG style)

แบบทดสอบเกมเมอร์ 16 สาย TH/EN พร้อมตัวละคร chibi และการ์ด IG Story
ผลวิจัยที่ใช้ออกแบบ: `../research/MBTI_Research.md` · Brief ภาพ: `../research/ART_BRIEF.md`

## เปิดดู (ต้องเปิดผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์)
```
cd app
python -m http.server 8766
```
แล้วเปิด http://127.0.0.1:8766 · ถ้าเปิดแบบ `file://` เบราว์เซอร์จะไม่ยอมให้เอาภาพตัวละครใส่ในการ์ด Story

## การให้คะแนน
- 20 ข้อ แกนละ 5 ข้อ แต่ละข้อมี 4 ระดับ (+2, +1, −1, −2) ไม่มีตัวเลือกตรงกลาง
- คะแนนรวมแต่ละแกนเป็นเลขคี่เสมอ จึงไม่มีผลเสมอ
- % ของแกน = 50 + |คะแนนรวม| / 10 × 50 (ได้ค่า 55–100%)
- ฝั่งที่ชนะได้ไม่เกิน 60% = ติดป้าย "ก้ำกึ่ง" และบอกผู้เล่นว่าผลอาจพลิกเมื่อทำซ้ำ

## ดีไซน์แบบเว็บยุคใหม่
- พื้นหลังแสงออโรราที่เปลี่ยนสีตามกลุ่มของผลลัพธ์ + เนื้อ grain
- การ์ดกระจกฝ้า (glassmorphism) จัดเป็นตารางหลายขนาด (bento grid)
- ปุ่มหลักมีขอบเรืองแสงหมุน, ตัวละครลอยและเอียงตามเมาส์ (3D tilt)
- เปลี่ยนหน้าด้วย View Transitions และเนื้อหาค่อยๆ โผล่ตอนเลื่อนลง (เฉพาะเบราว์เซอร์ที่รองรับ)
- สีแบบ OKLCH · ฟอนต์ Bricolage Grotesque + Anuphan (ไทย)
- รองรับมือถือเป็นหลัก · ใช้คีย์บอร์ดตอบได้ (ปุ่ม 1–4, Backspace = ย้อนกลับ) · ปิดแอนิเมชันเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว

## ก่อนเปิดตัว
1. ใส่ `siteUrl`, `igHandle` ใน `CONFIG` ของ `data.js`
2. Deploy เป็นเว็บแบบ static (GitHub Pages / Netlify / Vercel)
3. ทำรูปพรีวิวตอนแชร์ลิงก์ (`og:image`) จากภาพของ GPT
4. ใส่ GA4 หรือ Plausible: โค้ดยิง event `quiz_start`, `quiz_complete`, `share_click`, `share_done`, `save_click`, `type_view` ไว้แล้ว

## ตัวนับผู้เข้าใช้งาน (v4.2)
- `server.js` (Node ไม่ใช้แพ็กเกจเพิ่ม) เสิร์ฟหน้าเว็บ + API นับยอด แทน Caddy
- `GET /api/stats` → `{ visitors, visits, completes }` · `POST /api/hit` ส่ง `{"e":"visit"|"start"|"complete"}`
- **ผู้เข้าใช้งาน (คน)** = เบราว์เซอร์ที่เข้ามาครั้งแรก (จำด้วย id สุ่มใน localStorage) · **เข้าชม (ครั้ง)** = 1 ครั้งต่อ 1 session · **เล่นจบ (ครั้ง)** = ทำครบ 20 ข้อ
- เก็บที่ `/data/stats.json` บน Railway volume `stats` (ไม่หายเมื่อ deploy ใหม่) มียอดรายวันและสัดส่วนแต่ละสาย/เพศใน `daily`, `byType`
- ไม่เก็บข้อมูลส่วนตัว IP ใช้จำกัดความถี่ (30 ครั้ง/นาที) ในหน่วยความจำเท่านั้น
- เวอร์ชัน GitHub Pages ไม่มี API จึงซ่อนตัวนับอัตโนมัติ
