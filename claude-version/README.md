# Gamer Type Quiz: คุณเป็นเกมเมอร์สายไหน? (TH/EN)

แบบทดสอบ 12 ข้อ ได้ผลเป็น 1 ใน 16 สายเกมเมอร์ (แบบ 4 ตัวอักษร) พร้อมการ์ดผลลัพธ์ขนาด IG Story 1080×1920

## เปิดดู
```
cd claude-version
python -m http.server 8765
```
แล้วเปิด http://127.0.0.1:8765 (ใส่ `?lang=en` หรือ `?lang=th` ได้)

## ไฟล์
- `index.html`: หน้า intro → quiz → result
- `data.js`: คำถาม, ข้อความ UI, 16 สาย (TH/EN), `CONFIG` (เว็บไซต์, IG, ผู้สนับสนุน, ลิงก์ affiliate)
- `app.js`: การให้คะแนน, วาดการ์ด Story, แชร์/บันทึก/คัดลอกลิงก์
- `style.css`: ดีไซน์มือถือเป็นหลัก

## สิ่งที่ทำให้คนแชร์ใน Story
- ใช้เวลาไม่ถึง 2 นาที, แถบความคืบหน้าแบบ IG Story
- การ์ดผลลัพธ์ 9:16 พร้อมแชร์: emoji, รหัส 4 ตัว, ชื่อสาย, คำโปรย, แถบ 4 แกน, แนวเกม, คู่หู
- เนื้อหาหลักไม่โดนแถบบนและแถบตอบกลับด้านล่างของ IG บัง
- ปุ่ม "แชร์ลง Story" ใช้ Web Share บนมือถือ (เลือก Instagram ได้เลย); ถ้าแชร์ไม่ได้จะบันทึกรูป และบอกให้กดค้างเพื่อเซฟ (ใช้ได้ในเบราว์เซอร์ของ IG/LINE)
- "คู่หูที่เข้ากันที่สุด" + "แท็กเพื่อน": ทำให้คนแท็กเพื่อนและเกิดการแชร์ต่อ
- ลิงก์ผลลัพธ์ `?r=INFJ`: เพื่อนที่เปิดลิงก์จะเห็นผลของคุณ แล้วถูกชวนให้ทำแบบทดสอบเอง

## ต้องทำก่อนเปิดตัว
1. ใส่ `siteUrl` และ `igHandle` ใน `data.js` (พิมพ์ลงบนการ์ด)
2. Deploy เป็นเว็บแบบ static (GitHub Pages / Netlify / Vercel / OpenBot site)
3. ทำรูป `og:image` สำหรับตอนแชร์ลิงก์
4. ใส่ GA4 หรือ Plausible: โค้ดยิง event `quiz_start`, `quiz_complete`, `share_click`, `share_done`, `save_click` ไว้แล้ว
5. เลี่ยงคำว่า "MBTI" ในชื่อแบรนด์/โฆษณา (เป็นเครื่องหมายการค้าจดทะเบียน); ใช้ "16 Gamer Types" แทน

## รายได้ (เรียงตามความเร็วที่ทำได้)
| ช่องทาง | ทำอะไร | เริ่มเมื่อ |
|---|---|---|
| Affiliate อุปกรณ์เกมมิ่ง | ลิงก์ Shopee/Lazada Affiliate (TH), Amazon Associates (EN) แยกตามสาย เช่น ISTP → เมาส์ FPS, ISFP → คีย์บอร์ดพาสเทล ใส่ใน `CONFIG.gear` | วันแรก |
| สปอนเซอร์จากแบรนด์ | ค่ายเกม/แบรนด์เกียร์/ทีมอีสปอร์ตซื้อกรอบการ์ดหรือ "เกมแนะนำประจำสาย" ใช้ `CONFIG.sponsor` | เมื่อมีตัวเลขจำนวนคนเล่น/แชร์ |
| ผลแบบพรีเมียม | 29–79 บาท: ผลละเอียด, ความเข้ากันกับเพื่อน, wallpaper มือถือประจำสาย (PromptPay/Stripe) | หลังพิสูจน์ได้ว่าคนแชร์จริง |
| Merch | สติกเกอร์, แผ่นรองเมาส์, เสื้อของแต่ละสาย (print-on-demand ไม่ต้องสต็อกของ) | เมื่อมีสายที่คนชอบชัดเจน |
| ช่องทางผู้ติดตาม | ให้ติดตาม IG / LINE OA เพื่อรับ "ผลเต็ม" → ได้ฐานคนดูไปขายสปอนเซอร์ (ต้องขอความยินยอมตาม PDPA) | วันแรก |
| B2B | แบบทดสอบความเข้ากันของทีมสำหรับกิลด์, ร้านเกม, ทีมอีสปอร์ต, งานอีเวนต์ | ระยะยาว |

ไม่แนะนำโฆษณาแบบ display เป็นรายได้หลัก: ทำให้การ์ด/หน้าเว็บดูถูกลงและลดการแชร์ ใส่เฉพาะท้ายหน้าผลลัพธ์ถ้าจะใส่
