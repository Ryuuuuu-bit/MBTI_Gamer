## 1. MBTI คืออะไร

| หัวข้อ | ข้อมูล | ความมั่นใจ |
|---|---|---|
| ผู้สร้าง | Katharine Cook Briggs กับลูกสาว Isabel Briggs Myers (สหรัฐฯ) | ✅ |
| ทฤษฎีต้นทาง | *Psychological Types* ของ Carl Jung ตีพิมพ์ปี 1921 (ฉบับอังกฤษ 1923) | ✅ |
| แบบสอบถามรุ่นแรก | Form A จดลิขสิทธิ์ปี 1943 ตามไทม์ไลน์ของ The Myers-Briggs Company; วางจำหน่ายเชิงพาณิชย์โดย CPP ปี 1975 | ⚠️ แต่ละแหล่งระบุปีต่างกัน |
| เจ้าของปัจจุบัน | ผู้จัดพิมพ์: The Myers-Briggs Company · "MBTI" และ "Myers-Briggs" เป็นเครื่องหมายการค้าจดทะเบียน | ✅ |
| สิ่งที่วัด | **ความชอบ (preference) ไม่ใช่ความสามารถ** คนส่วนใหญ่ถนัดฝั่งหนึ่ง แต่ใช้อีกฝั่งได้เมื่อจำเป็น | ✅ |

### 4 คู่ความชอบ (8 preferences)
| คู่ | ถามว่า | ฝั่งซ้าย | ฝั่งขวา |
|---|---|---|---|
| E / I | ได้พลังงานจากไหน | **E**xtraversion: โลกภายนอก คน กิจกรรม | **I**ntroversion: โลกภายใน ความคิด การอยู่เงียบๆ |
| S / N | รับข้อมูลแบบไหน | **S**ensing: ข้อเท็จจริง สิ่งที่จับต้องได้ ปัจจุบัน | i**N**tuition: แพทเทิร์น ความเป็นไปได้ อนาคต |
| T / F | ตัดสินใจด้วยอะไร | **T**hinking: ตรรกะ หลักการ ความเป็นธรรมแบบเป็นกลาง | **F**eeling: คุณค่า ผลกระทบต่อคน ความสัมพันธ์ |
| J / P | ใช้ชีวิตกับโลกภายนอกแบบไหน | **J**udging: วางแผน ปิดงาน มีโครงสร้าง | **P**erceiving: ยืดหยุ่น เปิดตัวเลือก ด้นสด |

> J/P **ไม่ได้** แปลว่า "ชอบตัดสินคน" หรือ "รับรู้เก่ง" เป็นแค่สไตล์การจัดการชีวิต

### Type dynamics: ฟังก์ชันหลัก/รองของแต่ละ type ✅
ในโมเดลของ Myers แต่ละ type มีฟังก์ชันหลัก (dominant) และฟังก์ชันรอง (auxiliary) ที่มีทิศทาง (E/I) ตรงข้ามกัน ฟังก์ชันลำดับ 3–4 เป็นการต่อยอดของนักทฤษฎีรุ่นหลัง ไม่ใช่ของ Jung

| Type | หลัก → รอง | Type | หลัก → รอง |
|---|---|---|---|
| ISTJ | Si → Te | ESTJ | Te → Si |
| ISFJ | Si → Fe | ESFJ | Fe → Si |
| INFJ | Ni → Fe | ENFJ | Fe → Ni |
| INTJ | Ni → Te | ENTJ | Te → Ni |
| ISTP | Ti → Se | ESTP | Se → Ti |
| ISFP | Fi → Se | ESFP | Se → Fi |
| INFP | Fi → Ne | ENFP | Ne → Fi |
| INTP | Ti → Ne | ENTP | Ne → Ti |

(i/e = ทิศทางภายใน/ภายนอก · S Sensing · N Intuition · T Thinking · F Feeling)

### 4 กลุ่มสี (temperament) ที่นิยมใช้ 💡
แบ่งตามแนวของ David Keirsey: **SJ** (ISTJ ISFJ ESTJ ESFJ) · **SP** (ISTP ISFP ESTP ESFP) · **NF** (INFJ INFP ENFJ ENFP) · **NT** (INTJ INTP ENTJ ENTP)
→ เราใช้เป็น **ธีมสี 4 กลุ่ม**ของ artwork และ UI (ไม่ใช่การอ้างทางวิทยาศาสตร์)

## 2. ความน่าเชื่อถือ: ต้องรู้ก่อนทำแบบทดสอบ

| ประเด็น | ข้อมูล | ความมั่นใจ |
|---|---|---|
| สถานะทางวิชาการ | นักจิตวิทยาจำนวนมากวิจารณ์ว่าเป็นวิทยาศาสตร์เทียม; โมเดล Big Five ได้รับการยอมรับในงานวิจัยมากกว่า | ✅ (มีข้อถกเถียง) |
| ผลเปลี่ยนเมื่อทำซ้ำ | Pittenger (1993) รายงานว่าทำซ้ำห่าง ~5 สัปดาห์ อาจได้ type ต่างไปถึง **ครึ่งหนึ่ง** สาเหตุหลักคือการแบ่งเป็น 2 ขั้วด้วยจุดตัด คนที่อยู่ใกล้กลางจึงพลิกง่าย | ⚠️ ข้อมูลเก่า ผู้จัดพิมพ์โต้แย้ง |
| ฝั่งผู้จัดพิมพ์ | อ้างค่า test-retest 0.81–0.86 (ทำซ้ำห่าง 6–15 สัปดาห์, n=1,721) | ⚠️ เป็นข้อมูลของเจ้าของเอง |
| ห้ามใช้คัดคน | The Myers-Briggs Company และมูลนิธิฯ ระบุชัดว่า **ไม่ควรใช้ในการรับคนเข้าทำงาน** | ✅ |

**ที่เราเอามาใช้:** คนที่ได้คะแนนก้ำกึ่งกลาง (~50/50) คือคนที่ผลพลิกบ่อยที่สุด ถ้าบอกเขาตรงๆ ว่า "แกนนี้ก้ำกึ่ง" จะซื่อตรงกว่า และยังเป็นเนื้อหาให้คุย/แชร์ต่อได้

## 3. MBTI ≠ 16Personalities

| | MBTI ทางการ | 16Personalities (NERIS) |
|---|---|---|
| เจ้าของ | The Myers-Briggs Company | NERIS Analytics Ltd. (UK) |
| ฐานทฤษฎี | Jung / type dynamics | ดัดแปลงจาก Big Five |
| สเกล | 4 คู่ ผลเป็นขั้ว | 4 คู่ + แกนที่ 5 Assertive/Turbulent (เช่น INTJ-A) แสดงเป็น % |
| ชื่อ type | ใช้รหัส 4 ตัว | ตั้งชื่อเอง เช่น Architect, Logician, Mediator |
| ฟรี? | เสียเงิน ผ่านผู้ให้บริการที่ได้รับอนุญาต | ฟรีออนไลน์ |

**ที่เราเอามาใช้:** แบบทดสอบ "MBTI ฟรี" ที่คนไทยส่วนใหญ่เคยทำคือ 16Personalities ไม่ใช่ MBTI ของจริง → **ห้ามใช้ชื่อ type ของเขา (Architect ฯลฯ) และห้ามเลียนสไตล์ภาพตัวละครของเขา** ชื่อสายเกมเมอร์ทั้ง 16 ของเราตั้งขึ้นเองแล้ว

## 4. ทำไมคนแชร์ MBTI ในโซเชียล

- **เกาหลีใต้** เป็นที่ที่กระแสชัดที่สุด คนรุ่นใหม่ใส่ type ไว้ใน bio ใช้ดูความเข้ากันตอนเดท และใส่ type ให้ตัวละคร ไอดอล หรือแม้แต่สินค้า แบรนด์ต่างๆ ใช้ MBTI ทำการตลาด ✅ (Korea Times, Korea Herald)
- นักวิจารณ์เตือนว่าการใช้ MBTI เลือกคนเดท/คนทำงานทำให้เกิดการแบ่งแยก ✅
- **ไทย**: ยังไม่เจอข้อมูลวิจัยหรือสถิติที่เชื่อถือได้ เจอแค่ข่าวการตลาด (ตุ๊กตาจับคู่ตาม MBTI) ⚠️ ถ้าจะใช้ตัวเลขฝั่งไทยต้องเก็บข้อมูลเอง
- สิ่งที่ทำให้แชร์ (💡 จากแพทเทิร์นข้างบน): ได้ป้ายสั้นๆ ที่บอกว่าตัวเองเป็นใคร · ได้เทียบกับเพื่อน/คู่ · มีภาพตัวละครแทนตัวเอง

### สัดส่วนประชากรแต่ละ type (สหรัฐฯ) ⚠️
แหล่งรองหลายแหล่งอ้างถึงตัวอย่างประชากรในคู่มือ MBTI: ISFJ ~13.8% · ESFJ ~12.3% · ISTJ ~11.6% · INFJ ~1.5% (หายากที่สุด)
**ยังไม่ได้ตรวจกับคู่มือต้นฉบับ และไม่ใช่ข้อมูลไทย** → **ห้ามพิมพ์ "มีแค่ X%" บนการ์ด** จนกว่าจะมีสถิติจากผู้เล่นของเราเอง

## 5. งานวิจัยฝั่งเกมเมอร์ (ใช้ประกอบการตั้งชื่อสายและคำถาม)

**Bartle (1996)** "Hearts, Clubs, Diamonds, Spades" แบ่งผู้เล่นเกม MUD เป็น 4 แบบ: Achievers ♦ · Explorers ♠ · Socialisers ♥ · Killers ♣ ✅ Bartle เองเตือนว่าไม่ควรเอาไปใช้กับเกมทุกประเภท

**Quantic Foundry Gamer Motivation Model** (Nick Yee) ✅ (ข้อมูลจากผู้พัฒนาโมเดลเอง)
12 แรงจูงใจ จับเป็น 6 คู่: Action (Destruction, Excitement) · Social (Competition, Community) · Mastery (Challenge, Strategy) · Achievement (Completion, Power) · Immersion (Fantasy, Story) · Creativity (Design, Discovery)
- สร้างจากข้อมูลผู้เล่นกว่า 30,000 คนตอนแรก และ 520,000+ คนในรายงานภายหลัง
- พบว่า Big Five มีความสัมพันธ์กับแรงจูงใจในการเล่นเกม **ในระดับภาพรวมประชากร ไม่ใช่ระดับบุคคล**

### การจับคู่แกนกับแรงจูงใจในเกม 💡 (สมมติฐานออกแบบ ไม่มีงานวิจัยรองรับโดยตรง)
| แกน | ฝั่งซ้ายในเกม | ฝั่งขวาในเกม |
|---|---|---|
| E / I | Social: Community, เล่นเป็นทีม, voice chat | เล่นเดี่ยว, ดื่มด่ำคนเดียว |
| S / N | Action/Mastery: ฟีลการควบคุม, ระบบ, เฟรมเรต | Immersion/Creativity: โลก, lore, Discovery |
| T / F | Competition/Strategy: เมต้า, ประสิทธิภาพ, ชนะ | Story/Community: ตัวละครที่รัก, อารมณ์ร่วม |
| J / P | Completion: แพลน, เก็บ 100%, บิลด์ล่วงหน้า | Excitement/Discovery: ด้นสด, ลองทุกอย่าง |

## 6. ข้อสรุปการออกแบบ (ใช้กับเว็บแอปเวอร์ชันใหม่)

1. **ชื่อแบรนด์:** "16 Gamer Types" / "เกมเมอร์ 16 สาย" ไม่ใช้คำว่า MBTI ในชื่อหรือโลโก้ ใช้ได้แค่ในเนื้อหาเชิงอธิบาย เช่น "ได้แรงบันดาลใจจากแนวคิดเรื่อง type ของ Jung/Myers-Briggs" พร้อมแจ้งว่าไม่ได้เกี่ยวข้องกับเจ้าของเครื่องหมายการค้า
2. **ความแม่นยำ:** เพิ่มจาก 12 เป็น **20 ข้อ (5 ข้อต่อแกน)** ใช้ **สเกล 4 ระดับ** (เห็นด้วยมาก/นิดหน่อย ทั้งสองฝั่ง ไม่มีตรงกลาง) → คะแนนรวมแต่ละแกนเป็นเลขคี่เสมอ จึงไม่มีผลเสมอ
3. **ความซื่อตรง:** แสดง % ของแต่ละแกน ถ้าแกนไหนอยู่ระหว่าง 40–60% ให้ติดป้าย "ก้ำกึ่ง" และบอกว่าผลอาจเปลี่ยนเมื่อทำซ้ำ
4. **ไม่อ้างเกินจริง:** "คู่หู" เป็นแค่คู่หูในเกมเพื่อความสนุก ไม่อ้างเรื่องความรักหรือการทำงาน · ไม่แสดง % ความหายากจนกว่าจะมีข้อมูลจริง · มี disclaimer "เพื่อความบันเทิง"
5. **ไม่ลอก 16Personalities:** ชื่อ, ภาพ, คำอธิบาย ต้องเป็นของเราเองทั้งหมด
6. **ห้ามใช้ผลในการคัดคน:** ถ้าขายแบบ B2B (เช่น ทีมอีสปอร์ต) ให้ขายเป็นกิจกรรมสร้างทีม ไม่ใช่เครื่องมือคัดเลือกผู้เล่น
